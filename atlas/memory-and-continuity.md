# Memory and continuity

A state can vanish while a structure derived from it remains usable. This is the distinction between preserving an experience and preserving a map that can orient action after the experience is gone.

The Loom's limited-access reading of one selected record moves from a state of felt connection into ordinary time, then tracks a cartographic role for what is remembered. The useful distinction is not “timelessness is true.” It is that the system needs a portable relation-set when immediate access changes.

The boundary matters: a remembered map is not the original state, and certainty inside an experience is not external verification. A map can also preserve the wrong relations.

Open question: what is the minimum structure that lets a later reader recover a discovery without inheriting the original author's whole context?
