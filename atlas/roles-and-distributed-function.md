# Roles and distributed function

A system can produce a coherent result even when no local participant represents the entire objective.

Across the selected records described here, the Loom tracks messages, people, artifacts, and interfaces in distributed configurations. Its reading discipline asks which component carries which function: fabrication, observation, routing, recognition, memory, authorization, or enactment.

Boundary: distributed function is not evidence of a hidden controller. Coherent group behavior can arise through shared rules, environmental feedback, institutions, imitation, or designed coordination.

Open question: what must each participant know for the whole system to remain recoverable rather than merely coordinated?
