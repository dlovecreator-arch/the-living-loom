# Start here

The Living Loom is an independent, AI-assisted study of Dana Sorman's work and a practical method for close reading, structural comparison, and original design. It does not begin by deciding what a symbol means. It begins by preserving what is actually present and asking what relationships are active.

## The fastest route: inspect the method

Start with [The room, the card, and the hinge](examples/00-inspectable-example.md). The entire source is included because it is an original demonstration. You can see the observation, strongest reading, serious rival, limit, and derived design without trusting a private archive.

Then read [Foundations](FOUNDATIONS.md) for the connected architecture: function versus carrier, map versus state, destination versus route, availability versus recognition, local direction versus route progress, distinct constraint changes, orientation versus evaluation, and practice versus purpose.

## Use it on your own material

Attach [LOOM_STARTER.md](starter/LOOM_STARTER.md) to an AI conversation and provide the actual source you want examined. No installation is required. The starter cannot retrieve the private Living Loom archive and must never imply that it can.

## Explore Dana-derived commentary

The [atlas](atlas/INDEX.md) holds six compact thematic notes and the three retained worked examples. These rely on a curated set of private source records. Their public evidence status is listed in [the selected source index](research/SOURCE_INDEX.md) and the machine-readable [source registry](research/SOURCES.jsonl). Limited-access means exactly that: the project has a preserved source witness, but this public release does not reproduce it and no verified public locator was found in the bounded release search.

## Keep four layers separate

- **Source:** what Dana or another cited source actually presents.
- **Interpretation:** what the Loom infers from it.
- **Rival or limit:** another account, missing channel, or boundary.
- **Construction:** a new method or design created from the encounter.

The distinction is not bureaucracy. It is what lets imagination expand without turning invention into quotation.
