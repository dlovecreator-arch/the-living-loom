# From insight to design

## The problem

A large research archive can contain more intelligence than a reader can access. If every use requires the whole archive, the archive has become a dependency rather than a memory system.

## The source-derived distinction

The Loom's limited-access reading in the first example distinguishes an originating state from the map it interprets as carried forward after that state recedes. Other Loom work separates a map from the route chosen through it, and recognition of a result from the result itself.

## The construction

The public release turns those distinctions into architecture:

- the private archive remains intact;
- this repository is a selected current view, not a dump;
- three entry routes traverse the same evidence differently;
- claims preserve origin, limit, and revision state;
- the starter contains enough method to act without claiming hidden retrieval;
- the manifest makes the exact public payload inspectable;
- correction changes the smallest justified claim while retaining history.

## Synthetic demonstration

Suppose a researcher studies ten notebooks and discovers a recurring distinction between a destination, an address, and a route. A weak export gives readers a summary: “navigation matters.” A stronger export gives one example, the three-part distinction, a counterexample where address does not grant access, and a prompt that asks new material which role is present.

The synthetic example is not Dana evidence. It demonstrates how a relation becomes a reusable instrument without pretending the instrument was hidden in the original source.

## Failure case

Portability fails if the starter refers to private files, if a readable display name replaces stable identity, or if a compact explanation erases the contradiction that made the distinction necessary.

## Next question

What is the smallest relation-set that lets a new reader generate a real insight and then trace exactly which part came from the source, the method, and their own construction?
